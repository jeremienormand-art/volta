# Volta Arcade

Le jeu de service de Galopins Arcade, habillé pour Volta : un espace barista dans une salle de sport. Deux minutes de service, le meilleur score gagne.

- **Jouer** : https://volta.jeremie-normand.workers.dev (une fois branché sur Cloudflare).
- **Le jeu en un fichier** : `dist/galopins-arcade.html` (s'ouvre directement dans un navigateur).
- **Ce qui fait Volta** : `src/theme.js` (nom, lieu, Instagram, adresse). Les visuels sont dans `assets/`.

Version : 1.5 (2 novembre 2026) — toute l’équipe dessinée : Etienne (9 expressions, accueil, icône) et Marie (5 expressions, carton). v1.4 : Michel et Fabien dessinés (expressions et cartons d’arrivée). v1.3 : Michel (3 expressions). v1.2 : boissons dessinées de Volta (tasse de chocolat en verre, matcha en 6 étapes, expresso, croissant). v1.1 : boissons (chocolat, matcha, expresso, croissant), personnages (Etienne, Michel, Fabien, Marie) et répliques de Volta, bonus de Michel sans erreur ; visuels de Galopins en attendant ceux de Volta. v1.0 : copie de Galopins Arcade 1.50 avec le nom, les partages et la story de Volta.
